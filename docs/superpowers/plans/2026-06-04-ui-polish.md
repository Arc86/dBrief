## Task B: Fix level meter — include system audio

**Files:**
- Modify: `Sources/dBrief/Audio/AudioCaptureManager.swift:241`

**Context:** `startTimer()` uses nil-coalescing (`??`), so `micWriter.peakLevel` always wins even when it's 0 and system audio is loud. The fix takes the `max` of both sources, which is correct in all three capture modes: mic-only (systemWriter is nil → 0), system-only (micWriter is nil → 0), and mixed (louder source wins).

- [ ] **Step 1: Change the peakLevel calculation**

In `AudioCaptureManager.swift`, find line 241 inside `startTimer()`. Replace:

```swift
self.peakLevel = self.micWriter?.peakLevel ?? self.systemWriter?.peakLevel ?? 0
```

With:

```swift
self.peakLevel = max(self.micWriter?.peakLevel ?? 0, self.systemWriter?.peakLevel ?? 0)
```

## Task C: Floating mini-player collapse

**Files:**
- Modify: `Sources/dBrief/UI/FloatingMiniPlayer.swift`

**Context:** `FloatingMiniPlayerController` is already `@Observable` and `@MainActor`. The plan:
1. Add `var isCollapsed = false` + `func toggleCollapse()` + `private func updatePanelSize()` to the controller.
2. Pass the controller into `MiniPlayerView` via `.environment(self)`.
3. In `MiniPlayerView`, add `@Environment(FloatingMiniPlayerController.self)` and a chevron button in the top row; conditionally show/hide the waveform and action buttons.

`updatePanelSize()` reads `window.contentView?.fittingSize` after a `DispatchQueue.main.async` deferral (giving SwiftUI one run-loop cycle to recompute layout), then resizes and re-anchors the panel to keep the top-right corner stationary.

- [ ] **Step 1: Add collapse state and helpers to the controller**

In `FloatingMiniPlayer.swift`, update `FloatingMiniPlayerController` to add these members (insert after the `isVisible` computed property, before the closing `}`):

```swift
// --- NEW: collapse support ---
var isCollapsed: Bool = false

func toggleCollapse() {
    isCollapsed.toggle()
    DispatchQueue.main.async { [weak self] in
        self?.updatePanelSize()
    }
}

private func updatePanelSize() {
    guard let window, let screen = NSScreen.main else { return }
    let fittingHeight = window.contentView?.fittingSize.height ?? 0
    let newSize = CGSize(width: Self.panelWidth, height: fittingHeight)
    let screenFrame = screen.visibleFrame
    let x = screenFrame.maxX - Self.panelWidth - Self.screenMargin
    let y = screenFrame.maxY - fittingHeight - Self.screenMargin
    window.setContentSize(newSize)
    window.setFrameOrigin(NSPoint(x: x, y: y))
}
```

Also update `dismiss()` to reset `isCollapsed`:

```swift
func dismiss() {
    window?.close()
    window = nil
    isCollapsed = false
}
```

    let parts = name.split(separator: "_", maxSplits: 2)
    guard parts.count == 3 else { return name }
    return String(parts[2]).replacingOccurrences(of: "-", with: " ")

- [ ] **Step 3: Replace formattedDate with relative timestamps**

Replace the existing `formattedDate` computed property in `HistoryItem`:

```swift
// Before:
var formattedDate: String {
    let formatter = DateFormatter()
    formatter.dateStyle = .short
    formatter.timeStyle = .short
    return formatter.string(from: date)
}

// After:
var formattedDate: String {
    let cal = Calendar.current
    let now = Date.now
    let timeFormatter = DateFormatter()
    timeFormatter.dateFormat = "h:mm a"
    let timeStr = timeFormatter.string(from: date)

    if cal.isDateInToday(date) {
        return "Today \(timeStr)"
    } else if cal.isDateInYesterday(date) {
        return "Yesterday \(timeStr)"
    } else if let days = cal.dateComponents([.day], from: date, to: now).day, days < 7 {
        let dayFormatter = DateFormatter()
        dayFormatter.dateFormat = "EEE"
        return "\(dayFormatter.string(from: date)) \(timeStr)"
    } else {
        let shortFormatter = DateFormatter()
        let year = cal.component(.year, from: date)
        let currentYear = cal.component(.year, from: now)
        shortFormatter.dateFormat = year == currentYear ? "MMM d" : "MMM d, yyyy"
        return shortFormatter.string(from: date)
    }
}
```
