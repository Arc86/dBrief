# Evernote, Google Keep, and Microsoft OneNote

dBrief also contains integrations for Evernote, Google Keep, and Microsoft OneNote.

> **Not currently available.** These integrations are built into dBrief but hidden from **Settings → Integrations** while they're being verified. The steps below describe how they work for when they're turned on.
>
> Looking for Notion? It's available now: see [Notion](notion.md).

---

## Evernote

### Setup

1. Go to **Settings → Integrations**
2. Turn on **Send to Evernote**
3. Enter your Evernote **Token**, and optionally a **Notebook ID**
4. Choose which fields to include

### What gets sent

Each recording creates one note in Evernote. Choose from: transcript, summary, action items, tags, sentiment, and the full Markdown export.

---

## Google Keep

### Setup

1. Go to **Settings → Integrations**
2. Turn on **Send to Google Keep**
3. Enter your Google **OAuth token** (the Keep API may need Google Workspace setup)
4. Choose which fields to include

### What gets sent

Each recording creates one note in Google Keep. Choose from: transcript, summary, action items, tags, sentiment, and the full Markdown export.

---

## Microsoft OneNote

### Setup

1. Go to **Settings → Integrations**
2. Turn on **Send to OneNote**
3. Enter a Microsoft Graph token, and optionally a **Section ID**
4. Choose which fields to include

### What gets sent

Each recording creates one page in OneNote. Choose from: transcript, summary, action items, tags, sentiment, and the full Markdown export.
