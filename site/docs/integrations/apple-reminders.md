# Apple Reminders

Create a reminder for each action item extracted from your recording.

## Setup

1. Go to **Settings → Integrations** and click **Apple Reminders**
2. Turn on **Send to Apple Reminders**
3. Click **Test connection** and grant Reminders access when macOS asks (if you denied it earlier, allow dBrief in System Settings → Privacy & Security → Reminders)

## How it works

After AI analysis generates action items, dBrief creates one reminder in Apple Reminders for each item. The reminders appear in your default reminders list, or in the list you name under **Default list**.

> **Note:** This integration only makes sense if AI analysis is enabled and generating action items. If no action items are found in a recording, no reminders are created.
