# Keyboard Shortcuts

## Global shortcut

This shortcut works anywhere on your Mac, even when dBrief is in the background.

| Shortcut | Action |
|---|---|
| **⌃⌥⌘R** (default) | Start or stop recording |

### Changing the shortcut

The record shortcut is configurable. Go to **Settings → Recording → Shortcut**, click the shortcut field next to **Start or stop recording**, and press the key combination you want. It must include at least one of Control (⌃), Option (⌥), or Command (⌘). A **Reset** button restores the default (⌃⌥⌘R).

> **Why ⌃⌥⌘R and not ⌘⇧R?** The default avoids clashing with the hard-refresh shortcut (⌘⇧R) used by Chrome and other browsers.

## While recording

These work in the menu bar panel, the floating recording controls, and the **Recording** menu when dBrief is the active app.

| Shortcut | Action |
|---|---|
| **⌥⌘P** | Pause or resume recording |
| **⌥⌘.** | Stop recording |

## Menu bar panel

| Shortcut | Action |
|---|---|
| **⌘R** | Start recording |
| **⌘L** | Open the recording library |
| **⌘,** | Open Settings |
| **⌘Q** | Quit dBrief |
| **Return** | On the review screen after you stop: process the recording |

## Call prompts

| Key | Action |
|---|---|
| **Return** | **Record call** (or **Stop** when a call has ended) |
| **Esc** | **Not now** (or **Keep recording**) |

## Recording library and viewer

| Shortcut | Action |
|---|---|
| **↑** / **↓** | Previous / next recording in the list |
| **Space** | Play or pause (not while typing) |
| **⌘1** / **⌘2** / **⌘3** / **⌘4** | **Summary**, **Transcript**, **Actions**, **Meeting Insights** tab (also in the **View** menu) |
| **⇧⌘F** | Open the [Focus Reader](../history/focus-reader.md) |
| **⌃⌘S** | Show or hide the recording sidebar |
| **⌘F** | Search the transcript |
| **⌘G** / **⇧⌘G** | Next / previous search match |
| **⇧⌘C** | Copy the open tab (**Copy Summary**, **Copy Transcript**, …) |
| **⇧⌘I** | **Ask dBrief AI** / **Hide dBrief AI** |
| **⇧⌘R** | **Show in Finder** |
| **⌘⌫** | **Delete Recording…** (asks first) |
| **←** / **→** | With the speaker timeline focused: skip back / forward a little |

The **Recording** menu also has **Play**, **Retranscribe…**, **Re-run AI Analysis…**, **Detect Speakers Again…**, **Rename Speaker…**, **This Is Me** and **Integrations…** for the open recording.

## Editing the summary

| Shortcut | Action |
|---|---|
| **⌘S** | Save |
| **Esc** | Cancel editing |
| **/** | Open the block menu (headings, lists, to-dos) |
| **⌥⇧↑** / **⌥⇧↓** | Move the current block up / down |

## Ask dBrief AI

| Key | Action |
|---|---|
| **Return** | Send the question |
| **Esc** | Stop a reply that's still being written |

## Focus Reader

| Key | Action |
|---|---|
| **Space** / **⇧Space**, **Page Down** / **Page Up** | Scroll a screen down / up |
| **↓** / **↑**, **Home** / **End** | Scroll a little, or jump to the top / bottom |
| **⌘1** / **⌘2** | **Notes** / **Transcript** |
| **⌘+** / **⌘−** | Larger / smaller text |
| **Esc** or **⇧⌘F** | Leave the Focus Reader |

## Speaker review ("Who's speaking?")

| Key | Action |
|---|---|
| **↑** / **↓** | Move through the suggested names |
| **Return** | Assign the highlighted name. With the name field empty: confirm all voices |
| **⌘↑** / **⌘↓** | Previous / next voice |
| **⌥Space** | Play or stop the voice sample |
| **Esc** | Cancel |

## Settings

| Shortcut | Action |
|---|---|
| **⌘F** | Search Settings |
| **↑** / **↓** | Move through the sidebar or search results |
| **⌘[** | Back to **All integrations** from an integration's page |

### Voice library (Settings → Speakers)

| Shortcut | Action |
|---|---|
| **↑** / **↓** | Select the previous / next person |
| **Shift-↑** / **Shift-↓** | Extend the selection |
| **⌘A** | Select everyone |
| **Return** | Rename the selected person |
| **⇧⌘M** | Merge the selected people |
| **Delete** | Forget the selected people (asks first) |

See [Language & Accessibility](language-and-accessibility.md) for VoiceOver support.
