# Keyboard Shortcuts

## Global shortcut

This shortcut works anywhere on your Mac, even when dBrief is in the background.

| Shortcut | Action |
|---|---|
| **⌃⌥⌘R** (default) | Start or stop recording |

## Changing the shortcut

The record shortcut is configurable. Go to **Settings → Recording → Shortcut**, click the shortcut field next to **Start or stop recording**, and press the key combination you want. It must include at least one of Control (⌃), Option (⌥), or Command (⌘). A **Reset** button restores the default (⌃⌥⌘R).

> **Why ⌃⌥⌘R and not ⌘⇧R?** The default avoids clashing with the hard-refresh shortcut (⌘⇧R) used by Chrome and other browsers.
