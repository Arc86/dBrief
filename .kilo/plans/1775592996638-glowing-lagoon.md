# Interactive Transcript Core — Implementation Plan

## Overview
Build an interactive transcript window with word-level audio sync, inline editing, and starred segments. Persisted as `.richtranscript.json` sidecar files.

| # | Task | Files (create/modify) |

| 1 | RichTranscript model + TranscriptionResult extension | Create `Models/RichTranscript.swift`, modify `TranscriptionResult.swift`, `Recording.swift` |
| 2 | TranscriptStore actor | Create `Services/TranscriptStore.swift`, `Tests/TranscriptStoreTests.swift` |
| 3 | RichTranscriptBuilder | Create `Services/RichTranscriptBuilder.swift`, `Tests/RichTranscriptBuilderTests.swift` |
| 4 | Word timestamps from remote TranscriptionService | Modify `Services/TranscriptionService.swift` (parseResponse) |
| 5 | Word timestamps from WhisperKit | Modify `Services/WhisperKitTranscriptionService.swift` |
